# EHDS

Research on the EU European Health Data Space (EHDS) Regulation, focused on what
Hospital Information Systems (HIS) / EMR / EHR vendors and healthcare providers
need to do to integrate — in Finland and other EU member states — and on the
market for gateway/integration components that connect legacy systems to EHDS.

**Published site: https://johnalexamon.github.io/EHDS/**
(Source: [docs/ehds-integration/index.md](docs/ehds-integration/index.md))

## Contents

- [`docs/ehds-integration/`](docs/ehds-integration/) — the finished, sourced deliverable (7 files: overview, legal/technical framework, implementation timeline, Finland, other member states, gateway market & API status, recommendations), including Mermaid diagrams for the timeline, gateway architecture, and country-readiness comparison
- [`website/`](website/) — the [Docusaurus](https://docusaurus.io/) site that renders `docs/ehds-integration/` as the published site above; built and deployed automatically via GitHub Actions on every push to `main`
- [`research_notes/`](research_notes/) — raw working notes from the underlying research pass
- [`reports/`](reports/) — an internal single-file concatenation of the research (for reference; the `docs/` folder is the primary deliverable)
