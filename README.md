# EHDS

Research on the EU European Health Data Space (EHDS) Regulation, focused on what
Hospital Information Systems (HIS) / EMR / EHR vendors and healthcare providers
need to do to integrate — in Finland and other EU member states — and on the
market for gateway/integration components that connect legacy systems to EHDS.

**Start here: [docs/ehds-integration/README.md](docs/ehds-integration/README.md)**

## Contents

- [`docs/ehds-integration/`](docs/ehds-integration/) — the finished, sourced deliverable (7 files: overview, legal/technical framework, implementation timeline, Finland, other member states, gateway market & API status, recommendations)
- [`research_notes/`](research_notes/) — raw working notes from the underlying research pass
- [`reports/`](reports/) — an internal single-file concatenation of the research (for reference; the `docs/` folder is the primary deliverable)
